## Project lineage

Hackathon Atlas surfaced [BlockTerms](https://ethglobal.com/showcase/blockterms-10te2) as adjacent work. The user-approved project boundary is: Start with a versioned Tamil invoice OCR suite, eligible providers that can process approved inputs, per-provider budget limits, field-level evaluation and reproducible buyer-private reports. Evaluate date, tax and total under deterministic typed rules. Show task-specific observations by provider, version and time window.

## External dependency

Benchmark repeatability, representative consented samples, collusion and a minimum sample size matter. Treat buyer labels as versioned inputs. Platform interfaces are documented in [provider notes](KITE-AND-PROVIDERS.md). Market demand, integration behavior, source data access and live payment authority require separate evidence.
