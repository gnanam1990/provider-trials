# Provider Trials · Demonstration script

**Input and expected outcome.** Two bound providers each process four invoices with three mandatory fields each under the same frozen suite. A accepts three invoices with 11/12 fields and spends 12 cents; B accepts two with 9/12 fields and spends 10 cents. Display 4 and 5 cents per accepted invoice, respectively, and 4/4 coverage. Results on four samples carry a small-sample warning. If A's settlement is missing, its cost efficiency is unknown until reconciliation.

**Operator surfaces.** Compare providers in rows with accepted invoices, attempted/scheduled, field denominators, error categories, spend, latency sample count, test date and binding expiry. Drill down to redacted field-level evidence. Show sample size warnings and unknown costs; evidence downloads inherit the buyer's ACL.

**Failure to demonstrate.** Persist a unique trial/provider/sample slot and durable attempts before paid dispatch. Recover original invocation on timeout where supported; otherwise preserve an uncertain charge. Separate retry policy from logical sample totals and aggregate spend across all attempts. Rebuild a report from its frozen source cursor.

Create a labeled, rights-cleared sample through the import or creation UI. Identify the seeded input separately from all real actions and receipts. Record with two appropriate role sessions where required, browser refresh and worker restart. Use a final export or read-only case view tied to the input revision; show any unsupported capabilities as such. Record actual outcomes next to expected outcomes in the target repo.
